## Agent

`conductor.Agent` is the core building block representing an intelligent agent powered by an LLM.

### Constructor

```python
from conductor import Agent

agent = Agent(
    name: str = "assistant",
    model: str = "llama-3.2",
    instructions: str = "",
    tools: list[Tool | Callable] = None,
    temperature: float = 0.7,
    max_tokens: int = 4096,
    memory: Optional[Memory] = None,
    config: Optional[Config] = None,
    **kwargs
)
```

#### Parameters

- **`name`** (`str`): Unique identifier for the agent (defaults to `"assistant"`).
- **`model`** (`str`): Model name to use. Defaults to `"llama-3.2"` (Ollama local model). Also accepts OpenAI (`"gpt-4o"`, `"gpt-4o-mini"`) or Anthropic (`"claude-3-5-sonnet"`, `"claude-3-opus"`).
- **`instructions`** (`str`): System instructions/prompt that dictates the agent's persona and objectives.
- **`tools`** (`list`): List of functions decorated with `@tool` or `Tool` instances available to the agent.
- **`temperature`** (`float`): Sampling temperature between `0.0` and `2.0`.
- **`max_tokens`** (`int`): Maximum response token generation limit.
- **`memory`** (`Optional[Memory]`): Optional memory instance for persistent context and conversation state.
- **`config`** (`Optional[Config]`): Optional configuration object for retries, timeouts, and tracing.

### Methods

#### `async run(prompt: str | list[Message], **kwargs) -> Response`
Executes a task or conversation turn and returns a complete `Response`.

```python
response = await agent.run("Summarize the quarterly earnings report.")
print(response.content)
```

#### `async stream(prompt: str | list[Message], **kwargs) -> AsyncIterator[Chunk]`
Streams token chunks in real-time as they are generated by the model.

```python
async for chunk in agent.stream("Explain quantum key distribution"):
    print(chunk.content, end="", flush=True)
```

## Tools

Tools give agents the ability to call external APIs, calculate data, or execute code.

### Decorator: `@tool`

Converts a Python function into an agent-callable tool. Conductor automatically inspects type annotations and docstrings to build the tool's JSON schema.

```python
from conductor import tool

@tool
def calculate_vat(amount: float, rate: float = 0.20) -> float:
    """Calculate value-added tax for a given amount.
    
    Args:
        amount: Base monetary amount
        rate: VAT rate percentage as a decimal (default 0.20)
    """
    return round(amount * rate, 2)
```

### Class: `Tool`

For manual or dynamic tool definitions:

```python
from conductor import Tool

custom_tool = Tool(
    func=my_function,
    name="custom_calculator",
    description="Custom calculator tool"
)
```

## Workflows

`conductor.Workflow` chains multiple agents in sequence, passing outputs between steps.

### Constructor

```python
from conductor import Workflow, Step

workflow = Workflow(
    name: str = "pipeline",
    steps: list[Step | tuple[str, Agent, str]] = None
)
```

### `Step`

Represents an individual step executed by a designated agent.

```python
step = Step(
    agent=researcher_agent,
    task="Research latest news regarding {topic}",
    name="research"  # optional step name
)
```

### Execution

```python
result = await workflow.run(topic="Renewable Energy Storage")
print(result)
```

Inputs and outputs are interpolated across steps using `{step_name.output}` or positional `{step_0}` references.

## Swarm

`conductor.Swarm` orchestrates collaborative multi-agent problem solving.

### Constructor

```python
from conductor import Swarm

swarm = Swarm(
    agents: list[Agent],
    coordinator: str = "hierarchical"  # "hierarchical", "round-robin", "consensus"
)
```

### Execution

```python
result = await swarm.run("Design an authentication architecture with OAuth2 and JWT.")
```

## Memory

`conductor.Memory` provides state and conversation persistence.

### Constructor

```python
from conductor import Memory

# In-memory storage (default)
memory = Memory(backend="memory", session_id="user-123", ttl=3600)

# Redis backend
memory = Memory(backend="redis", session_id="user-123", ttl=86400)
```

### Methods

- **`await memory.set(key: str, value: Any)`**: Store a value.
- **`await memory.get(key: str) -> Optional[Any]`**: Retrieve a stored value.
- **`await memory.delete(key: str)`**: Remove a key.
- **`await memory.append(message: Message)`**: Append a message to session conversation history.
- **`await memory.history() -> list[Message]`**: Retrieve conversation history.
- **`await memory.clear()`**: Clear session state.

## Configuration

### `Config`

```python
from conductor import Config, configure

config = Config(
    retry_attempts=3,
    timeout=30.0,
    enable_tracing=False,
    cache_ttl=3600
)

# Set global configuration defaults
configure(config)
```

## Data Types

### `Message`
```python
from conductor import Message

msg = Message(role="user", content="Hello, world!")
```

### `Response`
Returned by `agent.run()`:
- `content` (`str`): Generated text response.
- `tool_calls` (`list[ToolCall]`): List of executed tool calls.
- `usage` (`Usage`): Token consumption breakdown (`prompt_tokens`, `completion_tokens`, `total_tokens`).
- `model` (`str`): Model identifier.
- `finish_reason` (`str`): Completion reason (e.g., `"stop"`).
